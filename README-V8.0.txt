Deployment
----------
Extract this ZIP and upload ALL files and folders directly to the GitHub repository root.
Do not upload the enclosing moniruzzaman-moni-portfolio-v8.0 folder.

After committing:
1. Wait for GitHub Pages deployment.
2. Open the website in an incognito/private browser window.
3. Press Ctrl+F5.
4. Confirm these files load:
   /assets/css/site.css?v=80
   /assets/images/profile.jpg?v=80
   /assets/images/hero/toronto-skyline.jpg
